# CN Pronunciation

Russian-language personal Mandarin pronunciation trainer for classic HSK 1.

## Development
`npm install`
Copy `.env.example` to `.env.local` and add the iFlytek credentials.
Then `npm run dev`.

Credentials are intentionally server-side only.

## Features
Practice, reference audio, microphone assessment, per-syllable scoring, HSK 1 examples and a searchable full vocabulary list.
